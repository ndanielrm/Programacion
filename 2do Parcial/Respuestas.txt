 Implemente en la clase Laptop el método requerido por la interface
 correspondiente.
 El cálculo del precio final debe considerar:- Una depreciación del 12% por cada año de uso, debido a que las laptops
 pierden valor más rápido que las computadoras de escritorio.- Un descuento adicional del 15% relacionado al desgaste típico de
 portabilidad (batería, pantalla, bisagras, etc.).
 El método debe:- Calcular los años de uso,- Aplicar la depreciación anual,- Aplicar el descuento por portabilidad,
 Y retornar el precio final resultante.

public class Laptop extends Computadora implements Precio {

    private double precioBase;

    public Laptop(String marca, int modelo, String numeroSerie, int horasUso, double precioBase) {
        super(marca, modelo, numeroSerie, horasUso);
        this.precioBase = precioBase;
    }

    @Override
    public String verTipoDeComputadora() {
        return "Laptop";
    }

    @Override
    public double calcularPrecio() {
        // Calcular años de uso
        int aniosUso = horasUso / 8760; // aproximando 1 año = 8760 horas
        // Aplicar depreciación anual del 12%
        double precioDepreciado = precioBase;
        for (int i = 0; i < aniosUso; i++) {
            precioDepreciado *= 0.88; // 100% - 12% = 88%
        }
        // Aplicar descuento adicional del 15% por portabilidad
        precioDepreciado *= 0.85; // 100% - 15% = 85%
        
        return precioDepreciado;
    }
}
